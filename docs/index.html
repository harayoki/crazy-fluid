Crazy Fluid v1.00 by FXPluginHarness

画像を流体シミュレーションで歪ませます。仮想のスクリュー等を配置して入力画像をゆがませていきます。逆再生すると特撮でおなじみの演出に。 もっと読む

ブラウザ向けにWebAssemblyで動かしていますが、ローカルC++版はもっとスムーズに動きます。AE/Premiere/OpenFXのプラグイン版（近日公開）では画像ではなく動画をソースにする事も出来ます。各パラメータにキーを打てるので複雑なアニメーション作成が可能です。

0.000 s ? 全画面再生中のキー操作 スペース 再生 / 一時停止
→ + スペース 順方向に再生
← + スペース 逆方向に再生
Shift + → 最後のフレームへ
Shift + ← 最初のフレームへ
→ 1秒先へ（キーを離したとき）
← 1秒前へ（キーを離したとき）
Esc / ダブルクリック 全画面をやめる
